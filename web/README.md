# 指数狂飙 - Web指数看板

## 📊 功能介绍

这是一个实时指数监控看板，可以追踪全球主要指数的实时价格和枢轴点位。

### 支持的指数

- 🇺🇸 **美股指数**
  - 纳斯达克100指数 (NDX)
  - 标普500指数 (SPX)
  - 国际现货黄金 (XAUUSD)
  - 国际现货白银 (XAGUSD)

- 🇭🇰 **港股指数**
  - 恒生指数 (HSI)
  - 恒生科技指数 (HSTECH)

- 🇨🇳 **A股指数**
  - 沪深300指数 (CSI300)
  - 科创50指数 (KCB50)

## 🚀 快速启动

### 方法1：使用启动脚本（推荐）

在项目根目录运行：

```bash
python start_server.py
```

服务器会自动启动并打开浏览器。

### 方法2：使用Python内置服务器

```bash
cd web
python -m http.server 8888
```

然后在浏览器中访问：http://localhost:8888/index.html

## 📈 页面功能

### index.html - 完整指数看板（含枢轴点）

**主要功能：**
- ✅ 实时价格更新
- ✅ 多个月度和周度枢轴点显示
- ✅ 市场分类筛选（全部、港股、美股、大A）
- ✅ 时间范围调整（1天、1周、1月、3月）
- ✅ 自定义时间筛选
- ✅ 图表缩放和平移
- ✅ 智能自动更新（开盘时5分钟，盘后1小时）

**数据源：**
- Yahoo Finance（主要）
- 新浪财经（A股备用）

### dashboard-simple.html - 简单仪表板

**特点：**
- 🎯 简洁的数据展示
- 🎯 无枢轴点，专注价格趋势
- 🎯 适合快速查看

## 🔧 CORS代理（可选）

如果遇到数据加载问题（CORS错误），可以启动代理服务器：

```bash
python web/cors_proxy.py
```

然后在网页上点击"启用CORS代理"按钮。

**代理服务器配置：**
- 端口：8889
- 用途：解决Yahoo Finance API的跨域访问问题

## 💾 数据缓存

系统会自动缓存数据到浏览器的localStorage中：
- 缓存数据在页面刷新后依然可用
- 开盘时缓存5分钟，盘后缓存1小时
- 枢轴点数据版本化管理，更新时自动刷新

## 🎨 自定义配置

### 修改枢轴点数据

1. 打开index.html
2. 找到对应指数的配置（如`indices`数组）
3. 修改`monthlyPivots`和`weeklyPivots`数据
4. 刷新页面即可看到更新

### 添加新指数

在`indices`数组中添加新对象：

```javascript
{
    id: 'your_index',
    name: '指数名称',
    symbol: '代码',
    apiSymbol: 'Yahoo Finance代码',
    color: '#颜色代码',
    baseValue: 基准值,
    category: 'us/hk/cn',
    monthlyPivots: [...],
    weeklyPivots: [...]
}
```

## ⚠️ 注意事项

1. **数据延迟**：实时数据可能有5-15分钟延迟
2. **网络依赖**：需要稳定的网络连接
3. **市场时间**：盘后数据更新频率降低
4. **浏览器缓存**：如遇问题可清除浏览器缓存

## 🐛 常见问题

### Q: 数据不更新怎么办？
A: 
1. 检查网络连接
2. 尝试启用CORS代理
3. 清除浏览器缓存并刷新

### Q: 枢轴点不显示？
A: 检查配置的日期范围是否在当前时间范围内

### Q: 恒生科技指数只显示价格？
A: 这是正常的，该指数受数据源限制，只能获取最新价格
